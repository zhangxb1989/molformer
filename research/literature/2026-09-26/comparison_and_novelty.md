# 阶段 3：直接比较、创新缺口与 first 判断

## 核心判断

现有证据不支持“首次利用大模型识别多肽活性”或“首次将 MolFormer 用于多肽”。延续原多酚/代谢物课题时，合理定位是特定端点的数据集与应用评估研究。模型创新需要在统一数据与严格划分下证明，不能仅由更换预训练编码器推出。

## 可比性矩阵

直接比较要求相同预测单位、标签端点、训练测试集合、可用信息、指标和调参预算。本库中没有可直接拿其发表分数与用户项目分数排序的论文。

| 文献 | 关系 | 可比较的范围 |
|---|---|---|
| P24 植物化学物 QSPR | 83 种化合物到 TEER/Papp/ER，目前最接近端点的邻近研究 | 在共同 TEER 数据上重跑；不能拿 R² 对比 TJ 活性二分类 accuracy |
| P18/P19 抗氧化 QSAR | 化学对象或结构到活性的路线接近 | 可以复用基线；DPPH 标签不等于屏障保护 |
| P10/P16/P25 | 明确使用 MolFormer 的多肽先例 | 方法先例；结合活性不是多酚屏障效应 |
| P08/P14/P15/P21 | 肽化学表示、SMILES 预训练与性质预测 | 在共同肽数据上才可直接比较 |
| P04/P17/P23 | 阴性构建、外推评估与基线 | 迁移评估方法，并在本项目重新实验 |
| P20 | 代谢组预测屏障指数 | 输入是样本代谢组，不是候选分子的 SMILES |
| P22 | MolFormer 相关分子生成 | 生成指标不能用于分类排名 |

补充核查：P14 PeptiVerse 的 Table 1 将历史 PepLand c-CPP/c-Sol 分数 0.838/0.662 列在 Best F1 下，但 [P09 原 Table 1](https://academic.oup.com/view-large/527864395) 标为 AUC；[P14 正式 PDF](pdfs/P14_2026_PeptiVerse.pdf) p.5 还明确历史研究与本研究划分不同。因此该表不能作为同指标、同划分的优越性证据。

多标签论文仅作为另一任务设定的参考；原课题只有一个标签时，无须为追随文献改任务。

## First 声明审查

| 拟用声明 | 判断 | 依据 |
|---|---|---|
| 首次用大模型预测多肽活性/性质 | 不成立 | P02、P05 等 |
| 首次用 SMILES 语言模型预测多肽性质 | 不成立 | P08、P10、P14 等 |
| 首次将 MolFormer 用于多肽 | 不成立 | P10、P16 LANTERN、P25 TIDE；P21 也将其作为基线 |
| 首次用机器学习预测植物化学物肠屏障相关性质 | 范围过宽，不可使用 | P24 已预测 TEER、Papp、ER |
| 首次用 MolFormer 预测多酚/代谢物 ZO-1、Occludin、Claudin-3 相关活性 | 本轮未检得完全相同设置，仍不能确认 first | 三年检索不等于全历史查新；还需固定标签并做全时段数据库及引文追踪 |
| 证明 MolFormer 优于传统模型 | 待实验 | 必须同数据、同划分、同预算重跑，报告不确定性 |

建议表述：**“本研究评估分子预训练表征在多酚及其代谢物肠屏障相关活性预测中的适用性，并与指纹和分子描述符基线进行统一比较。”** 这是研究目的，不预先承诺模型优越性。检索未找到先例不能证明先例不存在。

## 原项目需要审计的事项

以下来自既往稿件版本核对，不是已经验证的最终训练数据事实。未将未发表稿件原文上传。

1. 早期英文稿记录 128 个化合物、122 阳性和 6 个无显著作用；较新中文四稿记录 109 个。需要当前数据版本、去重规则与类别计数，不能把旧比例套用新版本。
2. 既往以 ZO-1、Occludin、Claudin-3 任一上调定义阳性。未测量、未报道、无显著变化、明确无活性需要分别记录。细胞、剂量、时间与检测方法应作为标签来源信息保留。
3. 新稿六个外部候选实验上均为阳性，模型判对五个。5/6 只描述六个对象的一致情况，无法估计特异度；恒预测阳性会有 6/6，不能据此单独证明区分能力。
4. 当前 fork 官方 README 的公开 checkpoint 为约 1 亿分子训练；稿件若写 11 亿，需要核对实际权重名称、来源和哈希，不能以原论文最大规模代替实际使用规模。
5. 随机划分成绩不等于结构外推。重复分子、相近骨架和相同来源文献跨集合会改变结论。

## 有价值的研究缺口与最小验证方案

| 缺口 | 应形成的证据 | 对应贡献 |
|---|---|---|
| 标签来源不透明 | 规范 SMILES、DOI、实验条件、测量端点、标签理由、未知标签 | 可复核的数据集 |
| 小样本结果依赖划分 | 化合物去重；骨架/相似性分组与文献来源分组；在分组约束下尽可能保留类别分布 | 可靠泛化评估 |
| 预训练收益不清楚 | 多数类；描述符 LR/RF；ECFP LR/SVM/RF；冻结 MolFormer+简单头；受控微调 | 实际增量而非模型规模宣传 |
| 类别失衡、阈值不明确 | 训练/验证内选权重、阈值与校准，测试不参与选择 | 可解释的筛选规则 |
| 缺少不确定性 | 重复分组划分、配对比较、按独立分子/来源计算区间，公开失败划分 | 稳定性证据 |

二分类主报告 MCC、PR-AUC（给阳性率基线）、balanced accuracy、灵敏度、特异度与混淆矩阵；ROC-AUC、F1、accuracy 为补充。测试折只有一类时，应报告有关指标不可计算，不能补造 AUC。阴性极少时，先做数据审计；增加网络复杂度不能补足辨识证据。

若获得定量 TEER、表达量或通透性，可另定义回归，保持单位与条件一致，不把多个端点混为一个数。本轮仅完成文献与方案分析，没有训练模型或产生新的性能结果。
