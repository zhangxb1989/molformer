# MolFormer文献研究：逐篇速读入口

**先打开 [28篇文献独立分析索引](papers/README.md)。** 每篇都有单独文档，按六项整理：

1. 做了什么研究
2. 用了什么模型
3. 用了什么数据集
4. 最后结果怎么样
5. 贡献是什么
6. 缺陷与局限是什么

每篇附原论文入口、已归档PDF链接（如有）、阅读范围与前后篇跳转。贡献和局限是阅读归纳；结果注明对应任务和指标，资料不足的地方保留说明。
